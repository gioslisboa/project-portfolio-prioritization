## Overview

Organizations often need to decide which projects should receive priority when resources are limited.

This project proposes a decision-support framework that combines the Gaussian Analytic Hierarchy Process (AHP-G) with Monte Carlo simulation to prioritize project portfolios under uncertainty.

The methodology integrates multicriteria decision analysis, stochastic simulation and data visualization to support strategic decision making.

## Features

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Gaussian AHP implementation
- Monte Carlo simulation
- Sensitivity analysis
- Project ranking visualization
